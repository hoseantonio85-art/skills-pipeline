# Примеры использования

## Явно выбрать NORM

```text
Используй formulate-product-task.
Контекст: norm.

Идея: риск-менеджер должен быстрее понимать, какие изменения по контрагентам требуют реакции.
```

## Явно выбрать ORM

```text
Используй formulate-product-task.
Контекст: orm.

Идея: ...
```

Если ORM не подключён, skill должен остановить загрузку контекста и предложить:

1. указать путь к ORM;
2. выбрать NORM;
3. продолжить без контекста.

## Работать без контекста

```text
Используй formulate-product-task без продуктового контекста.

Идея: ...
```

Результат должен содержать предупреждение, что:

- существующие capabilities не проверялись;
- границы сервисов не подтверждены;
- бизнес-правила требуют проверки;
- прямой статус `READY_FOR_UX` недоступен.

## Контекст не указан

```text
Сформулируй продуктовую задачу:
нужно улучшить мониторинг изменений.
```

Skill должен спросить:

```text
Какой контекст использовать: norm, orm или без контекста?
```

## Project-level автоматический выбор

В текущем проекте существует:

```text
.gigacode/product-context.yaml
```

со значением:

```yaml
context_id: norm
```

Skill использует NORM без дополнительного вопроса, если пользователь не указал другой контекст.
