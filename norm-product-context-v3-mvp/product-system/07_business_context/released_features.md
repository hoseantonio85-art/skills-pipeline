# Подтверждённые релизы и фичи

## Статус

`not-connected`

В текущем репозитории нет источника, который позволяет достоверно определить:

- какие возможности реально выпущены;
- в какой версии;
- когда они стали доступны;
- для каких пользователей;
- под каким feature flag;
- какие части продуктовой модели являются только концепцией.

## Правило для skill

Нельзя использовать `known_capabilities.md` как доказательство релиза.

При формировании Product Task Brief нужно писать:

```text
Похожая capability описана в продуктовой модели.
Факт её наличия в production не проверен.
```

## Как заполнять в будущем

Для каждой подтверждённой фичи фиксировать:

| Поле | Описание |
|---|---|
| Feature ID | стабильный идентификатор |
| Сервис | владелец capability |
| Название | краткое название |
| Release version | версия |
| Release date | дата |
| Evidence | PR, release note, задача или production-ссылка |
| Availability | роли / организации / feature flag |
| Status | active / deprecated / removed |
| Last verified | дата проверки |

Пока таких записей нет.
