# Business Context — NORM

Раздел содержит структурированный продуктовый контекст, который используется
универсальным skill `formulate-product-task`.

## Назначение

Эти файлы помогают:

- определить затронутый сервис;
- не дублировать известные возможности;
- учитывать роли и границы сервисов;
- применять общие продуктовые правила;
- отделять подтверждённое описание продукта от предположений;
- фиксировать пробелы контекста.

## Что является точкой входа

```text
product-system/context-manifest.yaml
```

Manifest определяет:

- набор источников;
- их назначение;
- порядок загрузки;
- ограничения;
- текущую ревизию контекста.

## Принцип обновления

Контекст обновляется независимо от skill.

Когда меняется продукт:

1. обновить релевантный service-файл или business-context файл;
2. обновить `context_status.md`;
3. при появлении подтверждённого релиза обновить `released_features.md`;
4. проверить `known_capabilities.md`;
5. зафиксировать источник и дату;
6. не менять `SKILL.md`, если методика формулирования задачи не изменилась.

## Статус этой версии

Контекст собран из текущего `AI-PDLC-Design`.

Он пригоден для продуктовой постановки как структурированная основа, но требует
проверки владельцами продукта и не является доказательством production-поведения.
