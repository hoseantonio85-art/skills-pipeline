# Optional UI patterns

Каталог пока пуст и не блокирует MVP stage 03.

Будущий pattern должен содержать:

- stable ID и status;
- `use_when` и `do_not_use_when`;
- structure/slots;
- mandatory and optional states;
- UI Kit dependencies;
- constraints;
- source references и revision;
- один reference implementation при наличии.

Patterns читаются только по необходимости, а не всем каталогом.
