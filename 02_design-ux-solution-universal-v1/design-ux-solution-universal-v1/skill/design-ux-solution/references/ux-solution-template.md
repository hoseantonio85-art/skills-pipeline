# UX Solution Template

## 1. UX-задача

Кратко опиши изменение пользовательского опыта и связь с целью brief.

## 2. Концепция и rationale

Перечисли ключевые решения. Для каждого укажи: решение, причина, пользовательская ценность, компромисс.

## 3. Journey map

| Этап | Намерение пользователя | Нужная информация | Действие | Ответ системы | Риск/вопрос |
|---|---|---|---|---|---|

## 4. Сценарии

### Happy path

Нумерованный путь от входа до результата.

### Альтернативные сценарии

Опиши только значимые развилки, ошибки и возвраты.

## 5. Сущности и информационная модель

Сущности, их состояния, связи и признаки, влияющие на решение пользователя.

## 6. Information hierarchy

1. Главный сигнал.
2. Почему это важно.
3. Следующее действие.
4. Подтверждающие детали.
5. Служебная meta.

## 7. Surfaces и переходы

Обоснуй page, card registry, dashboard, modal, drawer и inline-слои, которые действительно нужны.

## 8. Состояния и feedback

Опиши релевантные loading, empty, error, partial, success и action progress.

## 9. Роль AI

Контекст, входы, результат, неопределённость, fallback и решение человека.

## 10. Structural handoff

| Surface | Назначение | Вход | Главная информация | Действия | Состояния | Переход/возврат |
|---|---|---|---|---|---|---|

## 11. UX acceptance criteria

Наблюдаемые критерии, по которым можно проверить прототип.
